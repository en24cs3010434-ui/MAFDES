# MAFDES – Military Aircraft Fault Diagnosis Expert System

🚀 **Live Demo:** https://mafdes-expert-diagnostics.streamlit.app/

MAFDES is an educational expert system designed to demonstrate fictional military aircraft fault diagnosis using rule-based reasoning.

## Features
- Rule-based diagnosis
- Forward and backward chaining
- Certainty factor
- Diagnosis explanation
- PDF report generation
- Interactive Streamlit interface
